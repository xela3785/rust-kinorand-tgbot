# 🎬 RandomFilmBot

Telegram-бот для коллективного выбора фильмов. Участники группы добавляют фильмы через ссылки с Кинопоиска, а бот помогает выбрать случайный фильм для совместного просмотра.

## ✨ Возможности

  - **Добавление фильмов** по ссылке с Кинопоиска с автоматическим получением метаданных (название, год, рейтинг, постер, описание)
  - **Случайный выбор фильмов** двумя способами:
    - `/random <N>` — выбрать N случайных фильмов из общего списка / из списка добавленных фильмов
    - `/random_per_user` — выбрать по одному фильму от каждого участника
  - **Отслеживание просмотренных** фильмов командой `/seen` - отметить просмотренным, `/unseen` - отметить непросмотренным
  <!-- - **Статистика** по количеству добавленных фильмов -->
  - **Автоматическая регистрация** участников при любом сообщении в чате

## 🚀 Быстрый старт

### Предварительные требования

- Rust 1.99+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))
- PoiskKino API KEY (получить на [api.poiskkino.dev](https://api.poiskkino.dev/documentation))

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/random-film-bot.git
cd random-film-bot
```

2. Создайте файл `.env` и скопируйте содержимое файла `.env.example` в него.

3. Запустите Бота:
```bash
cargo run
```
_____________

При первом запуске автоматически создастся база данных SQLite (films.db) и применятся миграции.


## 📖 Использование

### Доступные команды

| Команда          |                         Описание                          |
|:-----------------|:---------------------------------------------------------:|
| /start           |                        Приветствие                        |
| /help            |                       Список команд                       |
| /add <url>       |           Добавить фильм по ссылке с кинопоиска           |
| /list            |           Показать список добавленных фильмов             |
| /delete <url>    |           Удалить фильм по ссылке с кинопоиска            |
| /count           |            Показать количество фильмов в чате             |
| /random <N>      |                Выбрать N случайных фильмов                |
| /random_per_user | Выбрать по одному случайному фильму от каждого участника  |
| /seen <url>      |  Отметить фильм как просмотренный по ссылке с кинопоиска  |
| /unseen <url>    | Отметить фильм как непросмотренный по ссылке с кинопоиска |
| /join            |  Зарегистрироваться в чате (если еще не зарегистрирован)  |
| /leave           | Покинуть чат (Ваши фильмы не будут участвовать в /random) |


## Связь пользователей и чатов
- Пользователи добавляются в ЛС бота
- В групповых чатах пользователи автоматически регистрируются при любом сообщении
- Фильмы привязываются к пользователям через telegram_id
- Связь "фильм доступен в чате" определяется через JOIN с таблицей chat_members
